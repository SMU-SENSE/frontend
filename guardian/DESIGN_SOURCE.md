## 2026-09-16 보호자 화면 최신 handoff

보호자 영역은 2026-09-16 전달본을 최신 기준으로 사용한다. 이 전달본은 기존 개인 실험 저장소가 아니라 **`SMU-SENSE/frontend`의 `feature/dongseok` 브랜치에 구현하는 실제 팀 프론트 소스**다.

최신 전달본에 포함된 기준 화면/문서는 다음과 같다.

- `보호자용 화면 설계서 (26 10 16 수정)`
- `Screenshot_2026-09-16_at_17.23.19.png` — 첫 실행 온보딩 연출 참고
- `Screenshot_2026-09-16_at_19.36.18.png` / `19.36.38.png` — 루틴 스케줄러 및 루틴 추가
- `Screenshot_2026-09-16_at_19.38.40.png` / `19.38.47.png` — 환경 설정 및 계정 영역
- `Screenshot_2026-09-16_at_19.45.46.png` — 카테고리 편집
- `Screenshot_2026-09-16_at_20.07.54.png` — TTS 음성 설정

### 보호자 화면 구현 범위

- 최초 진입 온보딩 2단계
- 사용자 AAC 판과 동일한 보호자 라이브 AAC 뷰어
- 보호자 편집 모드 ON/OFF
- 신규 카드 추가 / 카드 선택 삭제 / 카테고리 편집 / 즐겨찾기
- 상징 카드 1초 롱 프레스 편집
- 환경 설정
  - 문장 이해 수준
  - 장소 관리 및 GPS 뷰어
  - 루틴 스케줄러
  - 2×2 / 3×3 / 4×4 격자
  - TTS 음성 및 속도
  - 보호자 리포트
  - 도움말 / 버전 정보
  - 로그아웃 / 회원탈퇴
- 보호자 리포트: 단어 사용 패턴, 카테고리 비율, 긴급 이벤트, 심박/표정/시간/장소 융합 영역

백엔드 API가 이미 존재하는 격자·TTS·카테고리·문장·알림 등은 실제 API를 사용한다. 아직 서버 계약이 없는 장소/GPS/센서/일부 개인화 설정은 프론트 구조와 상태를 먼저 구현하되, 가짜 서버 성공 응답을 만들지 않는다.

## 브랜드 구분 — M+ 사용 금지

팀 말모아 Guardian의 이름과 화면은 예서님 전달본을 기준으로 한다. 개인 AAC 실험에서 쓰는 `M+` 표기, 화면 하단 워터마크, 앱 제목, 설치 아이콘을 팀 결과물에 복제하지 않는다. `말모아 (4).zip`의 `Logo.png`가 브랜드 로고 원본 참고이며, 별도 확정된 앱 아이콘 원본이 제공되면 임시 아이콘을 해당 원본으로 교체한다.

## 개인 AAC 실험 저장소와의 구분

`usernameisuser11/malmoa-ai-personalization`은 별도의 개인 실험/검증 저장소이며 현재 작업 대상이 아니다. 이 문서의 디자인 handoff를 해당 저장소에 복제하거나 그 저장소의 demo/prototype UI를 팀 결과물의 기준으로 사용하지 않는다.

## 원본 범위 밖 기능

윤지님 Guardian 알림 API처럼 Figma handoff에 화면이 없는 기능은 API 연결 코드는 유지할 수 있지만,
새 시각 UI를 최종 디자인으로 간주하지 않는다. 해당 화면/컴포넌트 원본이 전달되면 그 소스로 교체한다.
